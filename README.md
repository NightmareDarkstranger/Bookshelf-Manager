# ShelfKeeper

ShelfKeeper is a Java EE web application that helps users organize and manage their personal book collections.

## Features

- Add books to a collection
- View all books in a library table
- Store data in a MySQL database
- JSP-based user interface
- Servlet and DAO architecture

## Built With

- Java 8
- JSP
- Servlets
- MySQL
- Maven
- Apache Tomcat
- IntelliJ IDEA

## Project Structure
